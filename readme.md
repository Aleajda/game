# Square Game

Консольная игра на C11: два игрока (пользователь и/или компьютер) поочередно ставят фишки на поле NxN. Побеждает тот, кто первым образует квадрат из своих фишек.  

---

## Содержание

- `src/` — исходники игры: `main.c`, `io.c`, `game.c`, `parse.c`, `print.c`  
- `game.h`, `io.h`, `parse.h`, `print.h` — заголовочные файлы  
- `Makefile` — для сборки  

---

## Сборка

1. Убедитесь, что у вас установлен GCC (поддержка C11).  
2. Откройте терминал в корне проекта и выполните команду:

```bash
make
```

3. После сборки появится исполняемый файл `game`.  

Для очистки объектных файлов и бинарника:

```bash
make clean
```

---

## Запуск

```bash
./game
```

Программа запустится и сразу покажет справку (`HELP`) с доступными командами.  

---

## Команды игры

### 1. HELP

Выводит описание всех доступных команд:

```bash
HELP
```

---

### 2. EXIT

Выход из игры:

```bash
EXIT
```

---

### 3. GAME

Начало новой игры.

**Формат:**

```bash
GAME N, U1, U2
```

- `N` — размер доски (целое число > 2)  
- `U1`, `U2` — игроки:

```bash
TYPE C
```

- `TYPE` — `user` (пользователь) или `comp` (компьютер)  
- `C` — цвет фишек: `W` (белые), `B` (черные)

**Пример:**

```
GAME 4, user W, comp B
```

→ Начнётся игра 4x4, первый игрок — пользователь с белыми фишками, второй — компьютер с черными.  

---

### 4. MOVE

Сделать ход для пользователя.

**Формат:**

```bash
MOVE X, Y
```

- `X`, `Y` — координаты клетки (от 0 до N-1, левый верхний угол = 0,0)  
- Выполняется только если текущий игрок — `user`.  

**Пример:**

```bash
MOVE 1, 2
```

→ Ставим фишку в колонку 1, строку 2.  

---

## Ход игры

- Игроки ходят по очереди.  
- Компьютер делает свои ходы автоматически и выводит:

```bash
C (X, Y)
```

где `C` — цвет фишки, `X, Y` — координаты хода.  

- После каждого хода проверяется победа или ничья.  

---

## Окончание игры

- Победа:

```bash
Game finished. C wins!
```

где `C` — цвет победителя (`W` или `B`).  

- Ничья (все клетки заняты, квадрат не образован):

```bash
Game finished. Draw
```

После завершения игры можно запускать новую с помощью команды `GAME`.  

---

## Примеры

1. **Пользователь против компьютера**

```bash
GAME 4, user W, comp B
MOVE 0, 0
B (1, 0)
MOVE 0, 1
B (2, 2)
MOVE 1, 1
B (3, 3)
MOVE 1, 0
Game finished. W wins!
```

2. **Компьютер против компьютера**

```bash
GAME 4, comp W, comp B
W (0, 0)
B (1, 0)
W (0, 1)
B (2, 0)
...
Game finished. B wins!
```
