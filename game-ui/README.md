# Square Game

Этот проект — веб-приложение на **React + TypeScript**, в котором реализована игра против бота.  
Игрок выбирает размер игрового поля, начинает игру и поочерёдно ставит фишки ("белые" или "чёрные") против алгоритма, который обрабатывает ходы на бэкенде.

---

## Возможности
- Выбор размера игрового поля от **3x3** до **50x50**.
- Выбор, кто начинает первым: **белые** или **чёрные**.
- Игрок делает ход, затем бот отвечает своим ходом.
- Определение **победителя** или **ничьей**.
- Кнопка **"Новая игра"** для сброса состояния и старта заново.

---

## Стек технологий
- **React** (Frontend)
- **TypeScript**
- **Tailwind CSS** (для стилей)
- **Axios** (для запросов на сервер)
- **Backend** (ожидается по адресу (http://localhost:8080/api/game/nextMove))

## Запуск проекта

### 1. Клонировать репозиторий
```bash
git clone https://github.com/Aleajda/game.git
```

### 2. Перейти в нужную ветку и установить зависимости
```bash
npm install
```

### 3. Запустить frontend
```bash
npm run dev
```
После запуска проект будет доступен по адресу:
```
http://localhost:5175/
```
или порту, указанному Vite

### 4. Настроить backend
Frontend ожидает, что сервер работает на:
```
http://localhost:8080/api/game/nextMove
```

## Примечания
- Если сервер недоступен, ходы бота выполняться не будут.
- Для корректной работы убедитесь, что backend запущен и доступен по адресу (http://localhost:8080).
