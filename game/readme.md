# Square Game

Web-сервис, вычисляющий  по заданному состоянию доски для игры в квадраты очередной ход

---

## Содержание

- `src/main/java` — исходный код сервера (контроллеры, сервисы, DTO, исключения игровая логика)
- `src/main/resources` — конфигурационные файлы
- `pom.xml` — Maven-проект
- `.mvn/` — Maven Wrapper для сборки и запуска без глобальной установки Maven

---

## Сборка

1. Убедитесь, что установлены:
   - Java 21+ 
   - Maven (или используйте встроенный mvnw)
   
2. Склонируйте репозиторий:
```bash
git clone https://github.com/Aleajda/game.git
```
3. Перейдите на ветку task2and3
4. Соберите и запустите сервер:
```bash
.\mvnw spring-boot:run
```
5. После запуска сервер будет доступен по адресу:
```bash
http://localhost:8080
```

## Эндпоиты

### POST: `/api/game/nextMove`

#### Тело запроса:
```json
{
  "size": 3,
  "data": "wbbwwwbbb",
  "nextPlayerColor": "b"
}
```


| Поле              | Тип    | Обязательное | Описание                                                                      |
| ----------------- | ------ |--------------|-------------------------------------------------------------------------------|
| `size`            | int    | да           | Размер игрового поля                                                          |
| `data`            | string | да           | Строковое состояние доски (`пробел` — пустая клетка, `B`/`W` — фишки игроков) |
| `nextPlayerColor` | string | да           | Цвет игрока, чей ход следующий (`"B"` или `"W"`)                              |

#### Пример ответа:

```json
{
  "status": "move",
  "player": "W",
  "row": 2,
  "col": 3
}
```
Возможные значения поля `status`:
   - `"move"` — рассчитан следующий ход
   - `"win"` — найден победитель
   - `"draw"` — ничья

Таким образом, теперь можно интегрировать нашу игру в другие сервисы, используя это API
